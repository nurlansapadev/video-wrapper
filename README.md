# Video-Wrapper

Мастерская упаковки YouTube-видео: название, обложка, описание, главы, теги. Один проект на все каналы, один стиль работы. Правила для Claude — `CLAUDE.md`.

## Как начать

Скажите: **«начинаем оформлять эпизод 6»** (или «упакуем эп-6 Honest Lies»). Дальше проект сам ведёт по 8 шагам и спрашивает, что нужно. Первым попросит сценарий.

Другие команды: «продолжаем», «где мы?», «новый канал», «что умеешь?».

## Claude Code (локально)

Папка: `D:\YouTube-Studio\claude_projects\video-wrapper`. brief, VO (`*whisper*.json`), en-script кладите в `channels/<канал>/episodes/ep-NN/input/` (фото — по запросу в `input/refs/`). Claude ведёт `status.md`, результаты к загрузке — в `output/`.

## Claude web (claude.ai)

1. Создайте на GitHub репозиторий `video-wrapper` и запушьте эту папку.
2. В claude.ai создайте Project → подключите репозиторий (GitHub) как Project knowledge.
3. В поле **Project instructions** вставьте:

```
Ты работаешь в проекте Video-Wrapper. Перед любой работой прочитай CLAUDE.md из файлов проекта и следуй ему: это мастерская упаковки YouTube-видео с тремя уровнями настроек (CLAUDE.md → core/ → channels/<канал>/). Веди меня по шагам core/workflow.md, задавай по одному вопросу. У тебя нет доступа к диску: файлы не правь, отдавай готовый текст блоком, а в конце каждого шага — обновлённый status.md эпизода целиком. Отвечай по-русски, коротко.
```

4. После сессии в web сохраните выданный `status.md` и артефакты в репо — следующая сессия (в web или в Code) продолжит с того же места. После правок в Code делайте push — иначе web увидит старую версию.

## Новый канал

Скажите «новый канал» — проект проведёт по опроснику `channels/_template/README.md` и создаст `channels/<slug>/`.

## Структура

```
CLAUDE.md          уровень 1 — как работает проект
core/              уровень 2 — ремесло упаковки для любого канала
channels/<канал>/  уровень 3 — настройки канала + эпизоды
```
Приоритет: канал > core > CLAUDE.md.
