# Новый канал — опросник

> Проект ведёт Nurlan по этим блокам **по одному**: спросил блок → получил → записал в файл → следующий.
> Папка канала: `channels/<slug>/` — копия `_template/` (кроме этого README и `episode/`, они остаются шаблонами).

1. **Канал** → `channel.md`: название, ссылка, ниша, язык, аудитория (возраст, страна), голос/подача, расписание.
2. **Брендинг упаковки** → `branding.md` + `styles/`: стили обложки (свои или скопированные из другого канала), цвета, шрифты, логотип/водяной знак, 3–5 обложек-эталонов (своих или конкурентов).
3. **Названия** → `titles.md`: формулы, удачные/неудачные примеры, ключевые слова ниши, запреты.
4. **Обложки — процесс** → `thumbnails.md`: чем генерируем (модель, промпт-шаблон), как кладём текст.
5. **Описание** → `descriptions.md`: шаблон, обязательные блоки, дисклеймеры, ссылки.
6. **Метаданные** → `metadata.md`: базовые теги, хэштеги, плейлисты, категория, время публикации, конечная заставка.
7. **Журнал** → `journal.md`: прошлые эпизоды (дата, название, обложка, ссылка, метрики), если есть.

Если ответа нет — оставить `{не задано}` и использовать правило из `core/`.
