## Правила канала
- **Перед кредитами — строка `Honest Lies - ep-NN`** (номер эпизода двумя цифрами, пустая строка после). Метка для самого Nurlan: по описанию сразу видно, какой это эпизод (решение 07.10.2026).
- **Конец описания — всегда текст из `channels/honest-lies/video_credits_text.txt`, дословно, без правок** (решение Nurlan, 07.10.2026). Это единый финальный блок всех эпизодов: источники, иллюстрации, музыка, благодарность. Меняется только в самом файле.
- Голос описания — сдержанный Arny: без восклицательных знаков, без «shocking».
- Политиков называть по должности и году, без оценок.
- Источники — с годом. Цитаты — с говорящим.
- Разделитель блоков — длинное тире `—` на отдельной строке.

## Как пишем — по шагам (эталон EP-07, Nurlan 16.10.2026)
1. **Первые две строки — 3 варианта**, один рекомендовать. Требования:
   - **≤ ~140 знаков**, чтобы целиком влезло в поиск (EP-07: 124). Длинный вариант (180+) обрезается на полуслове — минус.
   - ключевые слова темы (имя, ведомство) — **в первом предложении** (EP-07: FBI, Rajiv Gandhi);
   - **продолжают вопрос названия, а не повторяют** его; дают ключ «о чём на самом деле» + новую петлю;
   - **не раскрывают удар ни одной обложки и ни одного A/B-названия** — проверить по каждому варианту теста (EP-07: ни «$350», ни «школы», ни ареста);
   - хорошо работает фраза из самого сценария (EP-07: «The press release left out one detail» — такт 2).
   - Варианты **выводить в чат таблицей** (строки · знаков · комментарий), а не только в `status.md`.
2. **Абзац ключевых слов** — формула: `The story runs from <место> to <место>, <место> and <место> in <год>. Along the way: <люди по роли>, <события>, <узнаваемые названия>.` Имена, места, эпоха — да; повороты и ответы — нет. Без слов ударов обложек.
3. **Строка-вопрос** перед главами — одна, без ответа (EP-06: «How does a breakfast tab buy…?», EP-07: «Who was really working for whom?»).
4. **Главы** — по расшифровке рендера (`core/metadata.md`), 10–12 на ~20 мин. Названия — крючки. **Поворот называть нейтрально** (EP-07: арест героя → «The knock on his door»), слова ударов обложек в главах не использовать. Тизер следующего эпизода в главы не выносить — это заставка.
5. **SOURCES & NOTES** — 10–12 главных из брифа: `Издание/автор, Название, Где вышло, год`. Ссылки research — не ставить.
6. `Honest Lies - ep-NN` → кредиты дословно (сверить с `video_credits_text.txt`) → хэштеги-география (`metadata.md`).
