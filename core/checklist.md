# checklist.md — Финальная проверка перед публикацией

> Проходится вслух, пункт за пунктом. Любое «нет» — назад к шагу.

## Обещание
- [ ] Название, обложка и первые строки описания обещают **одно и то же** — и ролик это закрывает
- [ ] Всё, что в упаковке, есть в ролике (факт, цифра, имя, цитата)

## Название
- [ ] Крючок в первых ~45 знаках, длина ≤ 65
- [ ] Есть ключевое слово темы
- [ ] Вопрос или зазор; если утверждение — доказано в ролике целиком
- [ ] Риски (политика, кликбейт) названы, решение принято осознанно

## Обложка
- [ ] Читается на 120 px
- [ ] Узнаётся рядом с прошлыми обложками канала
- [ ] Текст 2–4 слова, не повторяет название
- [ ] Правый нижний угол свободен
- [ ] Не совпадает с первым кадром ролика

## Описание
- [ ] Первые две строки — крючок с ключевым словом, не аннотация
- [ ] Источники реальные, дисклеймеры канала на месте

## Главы
- [ ] Сняты с финального рендера, первая — `0:00`, ≥ 3 глав, каждая ≥ 10 сек

## Публикация
- [ ] Теги прошли vidIQ, итог прислан
- [ ] Плейлист, «не для детей», язык
- [ ] Конечная заставка и карточки
- [ ] Закреплённый комментарий
- [ ] Время — по расписанию канала
- [ ] A/B-тест запущен, если были спорные варианты
- [ ] Паспорт эпизода в `channels/<канал>/journal.md` заполнен тем, что реально вышло; пустых полей нет (кроме метрик)
