# lessons.md — Общие уроки (для всех каналов)

> Сюда — то, что стоило времени и касается любой упаковки. Уроки одного канала — в `channels/<канал>/journal.md`.
> Формат: дата — урок — почему.

### 07.10.2026 — Вариант на обсуждение ≠ решение
Nurlan прислал название «на обсуждение», его записали в бриф как финальное. Финалом считается только явное «берём / утверждаю». До этого — «кандидат». Правило — в `CLAUDE.md`.

### 07.10.2026 — Загадка без ключа не работает
Название из трёх образов («козырь», «дешёвые чипы», «зонтик») без вопроса — зритель не понимает, чего он не знает. Загадке нужен один ключ: место и год, понятный парадокс или вопрос «почему».

### 07.10.2026 — Главы — только по рендеру
Таймкоды озвучки и видео расходятся: заставка и монтажные паузы. Главы снимаются с финального файла.
