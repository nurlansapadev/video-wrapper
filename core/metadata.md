# metadata.md — Главы, теги, публикация (ремесло, для любого канала)

> Набор тегов, плейлисты канала — `channels/<канал>/metadata.md`.

## Главы

- **Есть финальный рендер — главы по нему** (решение 16.10.2026, EP-07): упаковщик сам расшифровывает в фоне — `ffmpeg -i <mp4> -vn -ac 1 -ar 16000 audio.wav` → `whisper audio.wav --model small --language en --word_timestamps True --output_format json` → `input/render-whisper.json` (~15–20 мин на CPU за 20 мин видео), таймкоды тактов ищет по первым словам. Точно, с учётом тизеров и вырезок.
- **Рендера нет** — по VO (таймкоды слов озвучки) + сдвиг монтажа, сверка двух глав в готовом ролике (`core/workflow.md`, шаг 6).
- Первая глава — строго `0:00`. Минимум 3 главы, каждая ≥ 10 сек, по возрастанию — иначе YouTube их не покажет.
- 6–12 глав на 15–30 минут.
- Название главы — **крючок**, а не оглавление: `The bill: ten dollars` лучше, чем `Introduction`. Тест «Анти-академичности» (`core/titles.md`) — и для глав.
- Глава не раскрывает ответ раньше ролика.

## Теги

- Играют малую роль — страховка для алгоритма, не двигатель.
- Порядок: главное ключевое слово → точные темы эпизода → общие темы канала.
- Лимит — 500 знаков. Без повторов, без нерелевантных популярных слов.

### Цикл с vidIQ (с EP-06)
1. **Упаковщик даёт список** одной строкой через запятую (готов к вставке), сгруппированный в ответе по слоям: точные (эпизод) · тематические (пак шаблона) · базовые (канал). С запасом ~20% — часть отсеется.
2. **Nurlan вставляет при загрузке**, vidIQ ставит оценки. Слабые Nurlan удаляет, сильные подсказки vidIQ может добавить.
3. **Nurlan присылает итог** (скрин или список): что осталось, что удалено с оценками, что добавлено.
4. **Упаковщик фиксирует финал** в `output/metadata.md` эпизода (+ `output/tags_vN.txt`) и журнале канала: финальные теги + удалённые с оценкой. Удалённые дважды и больше — кандидат на вычёркивание из базового набора канала (предложить, не вычёркивать сам).

Итог упаковщика — **черновик**: в журнал идёт только то, что прошло через vidIQ.

## Хэштеги

- До 3 штук, показываются над названием. Больше 15 — YouTube игнорирует все.
- Только если канал их использует (`channels/<канал>/metadata.md`).

## Настройки публикации

- Аудитория: «не для детей» (если канал не детский).
- Язык видео и язык названия/описания — язык канала.
- Категория, плейлист — из настроек канала.
- **Конечная заставка** — последние 5–20 сек: следующий эпизод + подписка. Не перекрывать финальную фразу ролика.
- **Карточки** — на упоминании прошлого эпизода канала.
- **Закреплённый комментарий** — вопрос зрителю по теме ролика (провоцирует комментарии), не «подпишитесь».
- **Дату и время публикации упаковщик не предлагает и не спрашивает** — решает Nurlan (07.10.2026). Фактическое время — только в журнал после выхода.

## A/B-тест

YouTube Studio → Test & Compare. Ставить, когда два кандидата названия или обложки спорят. Режимы: Title only · Thumbnail only · **Title and thumbnail** (у каждой обложки своё название — когда обложки разного типа удара, EP-07). Новому каналу — **2 варианта, не 3**: мало показов, третий растягивает тест. Результат — в `channels/<канал>/journal.md`.
